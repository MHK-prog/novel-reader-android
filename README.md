# کتاب‌خوان اندروید — نسخهٔ ۰.۱.۰

این پروژه نسخهٔ اندرویدی وب‌اپ کتابخانه است. رابط وب از فایل‌های فعلی پروژه کپی شده و در WebView تمام‌صفحه اجرا می‌شود. در نسخهٔ وب اصلی، `index.html` و `app.js` در ریشه و آیکن‌ها در `icons/` هستند؛ بنابراین همین ساختار در `app/src/main/assets/www/` نگه داشته شده است.

## ساخت و نصب APK

1. Android Studio و Android SDK Platform 35 را نصب کن.
2. پوشهٔ `android-native` را در Android Studio با **Open** باز کن و منتظر بمان Gradle Sync کامل شود.
3. از منوی **Build > Build APK(s)** فایل نصب را بساز. فایل Debug APK در این مسیر قرار می‌گیرد:

   `app/build/outputs/apk/debug/app-debug.apk`

همین پروژه با دستور `./gradlew assembleDebug` (در ویندوز `gradlew.bat assembleDebug`) هم ساخته می‌شود. اولین بار Gradle و Android Gradle Plugin باید از اینترنت دریافت شوند؛ خود برنامه پس از نصب برای کارکردن به اینترنت نیاز ندارد.

## انتخاب پوشه و نگهداری داده‌ها

بار اول برنامه انتخاب‌گر پوشهٔ اندروید را باز می‌کند. پوشهٔ **Documents** را انتخاب کن؛ برنامه پوشهٔ `NovelReader` را داخل آن می‌سازد. اگر این پوشه از قبل وجود دارد، می‌توانی خود `NovelReader` را انتخاب کنی. دسترسی انتخاب‌شده به‌صورت ماندگار ثبت می‌شود.

برنامه از Storage Access Framework اندروید استفاده می‌کند. به همین دلیل در Manifest مجوزهای قدیمی `READ_EXTERNAL_STORAGE` و `WRITE_EXTERNAL_STORAGE` درخواست نشده‌اند؛ انتخاب پوشه دسترسی محدود و پایدار می‌دهد و با Scoped Storage نسخه‌های جدید اندروید سازگار است.

- `library.json`: فهرست کتاب‌ها، برچسب‌ها و وضعیت مطالعه.
- `chapter-<شناسه>.txt`: متن هر فصل.
- `novel-library-YYYY-MM-DD.json`: نسخهٔ پشتیبان ساخته‌شده از منوی برنامه.

فایل‌های بالا معمولی و قابل‌مشاهده‌اند و با فایل‌منیجر گوشی هم قابل مدیریت هستند. برای واردکردن نسخهٔ پشتیبان یا متن فصل، دکمهٔ ورود فایل در برنامه از انتخاب‌گر خود اندروید استفاده می‌کند.

برای انتقال کتابخانهٔ نسخهٔ وب، ابتدا از منوی آن نسخهٔ پشتیبان بگیر؛ سپس در اپ اندروید، از منو فایل پشتیبان را وارد کن. پس از واردکردن، اطلاعات در فایل‌های پوشهٔ `NovelReader` ذخیره می‌شوند.

## انتشار خودکار در GitHub Actions

1. محتوای این پوشه را در ریشهٔ یک مخزن GitHub قرار بده و push کن.
2. از تب **Actions** اجرای workflow با نام **Build Android APK** را باز کن.
3. پس از موفقیت، در بخش **Artifacts** فایل `novel-reader-android-debug` را دریافت کن؛ APK داخل آن است.

این workflow خروجی Debug می‌سازد. برای انتشار در فروشگاه، باید APK یا AAB نسخهٔ Release را با کلید امضای خودت امضا کنی.

## نکتهٔ امنیتی

پل JavaScript فقط به محتوای محلی این WebView وصل شده است و WebView مسیرهای خارج از assets را باز نمی‌کند. در این پروژه فایل HTML و جاوااسکریپت قابل‌اعتماد هستند؛ فایل‌های TXT و JSON داده محسوب می‌شوند و به‌عنوان کد اجرا نمی‌شوند.
