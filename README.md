# کتاب‌خوان اندروید — نسخهٔ 1.1.5

این نسخه رابط کاربری را با Viewهای بومی اندروید اجرا می‌کند و هیچ WebView یا چارچوب رابط کاربری بیرونی ندارد. امکانات آن شامل انتخاب چندکتابی، جلد قابل برش، نمایش دو ستونی کتاب‌ها، تگ‌های قابل جستجو، تنظیم تم و هفت رنگ، فونت وزیرمتن و Chapters است.

## ساخت APK

پیش‌نیازها: Android Studio یا Android SDK با Platform 36 و JDK 17.

در پوشهٔ پروژه اجرا کن:

```powershell
.\gradlew.bat assembleDebug
```

در Linux یا GitHub Actions:

```bash
./gradlew --no-daemon assembleDebug
```

APK خروجی:

```text
app/build/outputs/apk/debug/app-debug.apk
```

شناسهٔ برنامه `com.novelreader.app` حفظ شده و شمارهٔ نسخهٔ Android برابر 109 است؛ در نتیجه نسخهٔ 1.1.5 قابلیت نصب روی نسخه‌های قبلی با همان امضای پایدار را دارد. برای انتشار در فروشگاه، APK/AAB را با کلید انتشار خودت امضا کن.

## ذخیره‌سازی و انتقال داده

در اجرای اول پوشهٔ **Documents** را از انتخاب‌گر Android انتخاب کن؛ برنامه پوشهٔ `NovelReader` را در آن می‌سازد. اجازهٔ دسترسی فقط به همین پوشه و به‌شکل ماندگار ثبت می‌شود و مجوز کلی حافظه درخواست نمی‌شود.

- `library.json`: کتاب‌ها، نویسنده، تگ‌ها، وضعیت مطالعه و جای آخرین مطالعه
- `chapter-<شناسه>.md`: متن Markdown هر Chapter
- تصویرهای جلد در فضای داخلی خصوصی برنامه ذخیره می‌شوند و در فهرست فایل‌های عمومی یا گالری نمایش داده نمی‌شوند.

متن هر Chapter فقط در فایل `.md` ذخیره و از همان فایل خوانده می‌شود.
جلدهایی که در نسخه‌های قبلی داخل Documents ذخیره شده‌اند، هنگام اجرای برنامه به محل خصوصی منتقل و نسخهٔ عمومی آن‌ها پاک می‌شود. حذف نصب یا پاک‌کردن داده‌های برنامه، جلدهای خصوصی را هم حذف می‌کند.

## انتشار خودکار APK در GitHub

Workflow موجود در `.github/workflows/android-apk.yml` با هر Push پروژه را می‌سازد. فایل APK را از بخش **Actions → Build Android APK → Artifacts** دریافت کن.

برای اینکه APKهای بعدی روی نسخهٔ قبلی نصب شوند، کلید امضای ثابت را یک‌بار بساز و مقادیرش را در GitHub Secrets با نام‌های زیر قرار بده:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

راهنمای ساخت و ثبت کلید در [ANDROID_UPDATE_SIGNING.md](ANDROID_UPDATE_SIGNING.md) است. فایل JKS را در Git قرار نده.
Workflow بدون این کلید ثابت متوقف می‌شود تا APK با امضای موقت و غیرقابل‌به‌روزرسانی منتشر نشود.

## فایل‌های تصویری و فونت

آیکن نصب برنامه همان تصویر اصلی در `icons/drawable-nodpi/novel_reader_icon.png` است. آیکن‌های رابط کاربری به‌صورت VectorDrawable XML در `icons/drawable/` نگه‌داری می‌شوند و با تغییر رنگ پوسته نمایش داده می‌شوند. پوشهٔ `icons/` به‌عنوان منبع Android تنظیم شده تا هیچ فایل آیکنی بیرون آن نباشد. فونت وزیرمتن و مجوز آن داخل `app/src/main/assets/fonts/` قرار دارند.
