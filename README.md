# کتاب‌خوان اندروید — نسخهٔ 2.0.0

این نسخه رابط کاربری را با Viewهای بومی اندروید اجرا می‌کند و WebView ندارد. کتابخانهٔ «همهٔ کتاب‌ها» کتاب‌ها را از همهٔ مجموعه‌ها نشان می‌دهد. در مجموعه‌های سری، شمارهٔ هر کتاب کنار نامش می‌آید و پیشنهاددهنده تا تمام شدن کتاب‌های قبلی سراغ شماره‌های بعدی نمی‌رود. کتاب‌های کامل‌شده دوباره پیشنهاد نمی‌شوند. امتیاز ستاره‌ای تنها شانس همان کتاب را تغییر می‌دهد؛ وزن چند ژانر با میانگین محاسبه می‌شود تا کتاب‌های دارای ژانرهای بیشتر بی‌دلیل شانس اضافه نگیرند. ژانرهای محبوب و نویسندگان محبوب نیز با اثر محدود در پیشنهادها دخالت دارند. شاخص تعداد کلمات فقط پس از عبور از ۲۰٬۰۰۰ کلمه در حداقل پنج کتاب وارد پیشنهادها می‌شود و از تنظیمات عمومی قابل خاموش‌کردن است.

اطلاعات کتاب شامل جلد، توضیحات، ژانرها، تعداد Chapter، درصد مطالعه، شمارهٔ سری و امتیاز ستاره‌ای است. تنظیمات ژانرها امکان افزودن، تغییرنام، ادغام و حذف ژانرها را دارد؛ نویسندگان محبوب از کتابخانهٔ جداگانهٔ نویسندگان انتخاب می‌شوند. تنظیمات ظاهر شامل تم سیاه و سفید، هفت رنگ ساده، تم‌های گرادیانی و گزینهٔ تغییر تصادفی رنگ تم در هر بار ورود است. انتخاب چندکتابی و افزودن Chapter با شمارهٔ دلخواه نیز پشتیبانی می‌شود.

## محاوره‌ای‌ساز

از منوی کناری فایل JSON قوانین جایگزینی را وارد و فعال کن. فایل آرایه‌ای از جفت‌های `[متن اصلی، متن جایگزین]` است و در پوشهٔ مخفی `Documents/NovelReader/.plugins/colloquializer/` ذخیره می‌شود. هنگام مطالعه، بخشی از متن را انتخاب و گزینهٔ «ویرایش محاوره‌ای‌ساز» را بزن. می‌توانی قانون را به JSON اضافه کنی یا فقط همان مورد را در Chapter جاری تغییر بدهی.

در الگوها، `x` رشته‌ای از حروف فارسی را می‌گیرد؛ `n` وجود یا نبود «ن» را حفظ می‌کند؛ `s` فاصله، نیم‌فاصله یا نبود فاصله را می‌پذیرد؛ و `b` مرز واژه را خاموش می‌کند. `a` از واژه‌های تک‌واژه‌ای ثبت‌شده به‌عنوان مبدأ در قوانین دیگر انتخاب می‌کند. برای فعل‌ها یک جفت واژه‌نامه‌ای مثل `["vgکرد", "vhکن"]` اضافه کن و در قانون عمومی از `vg` در مبدأ و `vh` در مقصد استفاده کن، مثل `["خواهند vg", "می vhن"]`. هر بار پردازش فقط متن اولیه را می‌گردد؛ مقصدهای ساخته‌شده در همان اجرا دوباره پردازش نمی‌شوند. گزینهٔ تگ مخفی، مبدأ واقعی الگوهای دارای حروف لاتین را با `%hid{...}%` پیش از مقصد نگه می‌دارد؛ این نشانگر در صفحهٔ مطالعه پنهان می‌شود.

هنگام افزودن یا ویرایش کتاب، ژانرها را با `,` جدا کن؛ دکمهٔ `+` ژانرهای موجود را انتخاب و ژانرهای جدید را ایجاد و انتخاب می‌کند.

## ساخت APK

پیش‌نیازها: Android Studio یا Android SDK با Platform 36 و JDK 17.

در پوشهٔ پروژه اجرا کن:

```powershell
.\gradlew.bat assembleDebug
```

در Linux یا GitHub Actions:

```bash
./gradlew --no-daemon assembleDebug
```

APK خروجی:

```text
app/build/outputs/apk/debug/app-debug.apk
```

این نسخه شناسهٔ برنامهٔ `com.novelreader.app.v2` و شمارهٔ نسخهٔ Android برابر 200 دارد، بنابراین کنار نسخهٔ قبلی نصب می‌شود و آن را به‌روزرسانی نمی‌کند. این نسخه با کتابخانهٔ خصوصی تازه شروع می‌شود و اطلاعات یا فرمت فایل‌های نسخه‌های قبلی را وارد نمی‌کند. متن نسخهٔ داخل برنامه مستقیماً از اطلاعات APK خوانده می‌شود تا با نسخهٔ ساخته‌شده از Gradle ناهماهنگ نشود.

## ذخیره‌سازی

- اطلاعات کتابخانه و تنظیمات برنامه در فضای خصوصی همین نصب نگه‌داری می‌شوند.
- متن Chapterها به‌صورت فایل txt در Documents/NovelReader/<book-id>/<chapter-id>.txt ذخیره می‌شود.
- جلدها در Documents/NovelReader/.covers و نسخهٔ اصلی متن هنگام محاوره‌ای‌سازی در .chapter-originals قرار می‌گیرند.
- نسخهٔ 2.0.0 داده‌های نسخه‌های قبلی، فایل‌های library.json و فایل‌های Markdown را وارد نمی‌کند. پوشهٔ قدیمی دست‌نخورده می‌ماند؛ نصب تازه برای دسترسی به پوشه باید دوباره اجازه بگیرد.

## دانلود APK و تاریخچهٔ نسخه‌ها

[دانلود آخرین نسخه از GitHub Releases](https://github.com/MHK-prog/novel-reader-android/releases/latest). هر نسخه به‌شکل فایل مستقیم `.apk` منتشر می‌شود؛ برای نصب، فایل APK نسخهٔ موردنظر را از بخش **Assets** دریافت کن، نه فایل ZIP سورس.

نام فایل‌ها نسخه و معماری را مشخص می‌کند، برای نمونه: `NovelReader-Android-v2.0.0-universal.apk`. این پروژه کد Java دارد و کتابخانهٔ native وابسته به معماری (مانند `.so`) ندارد، بنابراین یک APK از نوع `universal` برای معماری‌های پشتیبانی‌شدهٔ Android ساخته می‌شود. حداقل نسخهٔ Android، نسخهٔ 6.0 (API 23) است.

تاریخچهٔ نسخه‌ها و یادداشت هر انتشار در صفحهٔ **Releases** نگه‌داری می‌شود. برای انتشار نسخهٔ بعدی، `versionName` و `versionCode` را در `app/build.gradle` افزایش بده، تغییر را روی `main` پوش کن، سپس tag هم‌نام نسخه را بساز و پوش کن؛ برای نمونه:

```bash
git tag v2.0.1
git push origin v2.0.1
```

Workflow فایل APK امضاشده را می‌سازد و مستقیماً به Release پیوست می‌کند. نام tag باید با `versionName` پروژه یکی باشد. یادداشت اولین انتشار نوشته می‌شود و انتشارهای بعدی یادداشت تغییرات را از commitها می‌سازند.

برای اینکه APKهای بعدی روی نسخهٔ قبلی نصب شوند، کلید امضای ثابت را یک‌بار بساز و مقادیرش را در GitHub Secrets با نام‌های زیر قرار بده:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

راهنمای ساخت و ثبت کلید در [ANDROID_UPDATE_SIGNING.md](ANDROID_UPDATE_SIGNING.md) است. فایل JKS را در Git قرار نده.
Workflow بدون این کلید ثابت متوقف می‌شود تا APK با امضای موقت و غیرقابل‌به‌روزرسانی منتشر نشود.

## فایل‌های تصویری و فونت

آیکن نصب برنامه همان تصویر اصلی در `icons/drawable-nodpi/novel_reader_icon.png` است. آیکن‌های رابط کاربری به‌صورت VectorDrawable XML در `icons/drawable/` نگه‌داری می‌شوند و با تغییر رنگ پوسته نمایش داده می‌شوند. پوشهٔ `icons/` به‌عنوان منبع Android تنظیم شده تا هیچ فایل آیکنی بیرون آن نباشد. فونت وزیرمتن و مجوز آن داخل `app/src/main/assets/fonts/` قرار دارند.
