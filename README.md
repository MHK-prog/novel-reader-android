# کتاب‌خوان اندروید — نسخهٔ 1.4.15

این نسخه رابط کاربری را با Viewهای بومی اندروید اجرا می‌کند و WebView ندارد. کتابخانهٔ «همهٔ کتاب‌ها» کتاب‌ها را از همهٔ مجموعه‌ها نشان می‌دهد. در مجموعه‌های سری، شمارهٔ هر کتاب کنار نامش می‌آید و پیشنهاددهنده تا تمام شدن کتاب‌های قبلی سراغ شماره‌های بعدی نمی‌رود. کتاب‌های کامل‌شده دوباره پیشنهاد نمی‌شوند. امتیاز ستاره‌ای تنها شانس همان کتاب را تغییر می‌دهد؛ وزن چند ژانر با میانگین محاسبه می‌شود تا کتاب‌های دارای ژانرهای بیشتر بی‌دلیل شانس اضافه نگیرند. ژانرهای محبوب و نویسندگان محبوب نیز با اثر محدود در پیشنهادها دخالت دارند.

اطلاعات کتاب شامل جلد، توضیحات، ژانرها، تعداد Chapter، درصد مطالعه، شمارهٔ سری و امتیاز ستاره‌ای است. صفحهٔ تنظیمات تگ‌ها امکان افزودن، تغییرنام، ادغام و حذف ژانرها و انتخاب نویسندگان محبوب را دارد. تنظیمات ظاهر شامل تم سیاه و سفید، هفت رنگ ساده، تم‌های گرادیانی و گزینهٔ تغییر تصادفی رنگ تم در هر بار ورود است. انتخاب چندکتابی و افزودن Chapter با شمارهٔ دلخواه نیز پشتیبانی می‌شود.

## محاوره‌ای‌ساز

از منوی کناری فایل JSON قوانین جایگزینی را وارد و فعال کن. فایل باید آرایه‌ای از جفت‌های `[متن اصلی، متن جایگزین]` باشد و در پوشهٔ مخفی `Documents/NovelReader/.plugins/colloquializer/` ذخیره می‌شود. هنگام مطالعه، بخشی از متن را انتخاب و گزینهٔ «ویرایش محاوره‌ای‌ساز» را بزن. می‌توانی قانون را به JSON اضافه کنی یا فقط همان مورد را در Chapter جاری تغییر بدهی.

هنگام افزودن یا ویرایش کتاب، ژانرها را با `,` جدا کن؛ دکمهٔ `+` ژانرهای موجود را انتخاب و ژانرهای جدید را ایجاد و انتخاب می‌کند.

## ساخت APK

پیش‌نیازها: Android Studio یا Android SDK با Platform 36 و JDK 17.

در پوشهٔ پروژه اجرا کن:

```powershell
.\gradlew.bat assembleDebug
```

در Linux یا GitHub Actions:

```bash
./gradlew --no-daemon assembleDebug
```

APK خروجی:

```text
app/build/outputs/apk/debug/app-debug.apk
```

شناسهٔ برنامه `com.novelreader.app` حفظ شده و شمارهٔ نسخهٔ Android برابر 149 است؛ نسخهٔ 1.4.15 قابلیت نصب روی نسخه‌های قبلی با همان امضای پایدار را دارد. برای انتشار در فروشگاه، APK/AAB را با کلید انتشار خودت امضا کن.

## ذخیره‌سازی و انتقال داده

در اجرای اول پوشهٔ **Documents** را از انتخاب‌گر Android انتخاب کن؛ برنامه پوشهٔ `NovelReader` را در آن می‌سازد. اجازهٔ دسترسی فقط به همین پوشه و به‌شکل ماندگار ثبت می‌شود و مجوز کلی حافظه درخواست نمی‌شود.

- `library.json`: کتاب‌ها، نویسنده، ژانرها، وضعیت مطالعه و جای آخرین مطالعه
- `chapter-<شناسه>.md`: متن Markdown هر Chapter
- تصویرهای جلد در پوشهٔ مخفی `.covers` داخل `NovelReader` ذخیره می‌شوند؛ فایل `.nomedia` مانع فهرست شدن آن‌ها در برنامه‌های گالری می‌شود. وزن ژانرها و کتاب‌های پیشنهادشده در فضای خصوصی برنامه نگه‌داری می‌شوند.

متن هر Chapter فقط در فایل `.md` ذخیره و از همان فایل خوانده می‌شود.
جلدهای نسخه‌های قبلی، هنگام اجرا به `NovelReader/.covers` منتقل می‌شوند و نسخه‌های قدیمی پاک می‌شوند. این پوشه همراه داده‌های Documents باقی می‌ماند، حتی اگر برنامه حذف شود.

## دانلود APK و تاریخچهٔ نسخه‌ها

[دانلود آخرین نسخه از GitHub Releases](https://github.com/MHK-prog/novel-reader-android/releases/latest). هر نسخه به‌شکل فایل مستقیم `.apk` منتشر می‌شود؛ برای نصب، فایل APK نسخهٔ موردنظر را از بخش **Assets** دریافت کن، نه فایل ZIP سورس.

نام فایل‌ها نسخه و معماری را مشخص می‌کند، برای نمونه: `NovelReader-Android-v1.3.3-universal.apk`. این پروژه کد Java دارد و کتابخانهٔ native وابسته به معماری (مانند `.so`) ندارد، بنابراین یک APK از نوع `universal` برای معماری‌های پشتیبانی‌شدهٔ Android ساخته می‌شود. حداقل نسخهٔ Android، نسخهٔ 6.0 (API 23) است.

تاریخچهٔ نسخه‌ها و یادداشت هر انتشار در صفحهٔ **Releases** نگه‌داری می‌شود. برای انتشار نسخهٔ بعدی، `versionName` و `versionCode` را در `app/build.gradle` افزایش بده، تغییر را روی `main` پوش کن، سپس tag هم‌نام نسخه را بساز و پوش کن؛ برای نمونه:

```bash
git tag v1.3.6
git push origin v1.3.6
```

Workflow فایل APK امضاشده را می‌سازد و مستقیماً به Release پیوست می‌کند. نام tag باید با `versionName` پروژه یکی باشد. یادداشت اولین انتشار نوشته می‌شود و انتشارهای بعدی یادداشت تغییرات را از commitها می‌سازند.

برای اینکه APKهای بعدی روی نسخهٔ قبلی نصب شوند، کلید امضای ثابت را یک‌بار بساز و مقادیرش را در GitHub Secrets با نام‌های زیر قرار بده:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

راهنمای ساخت و ثبت کلید در [ANDROID_UPDATE_SIGNING.md](ANDROID_UPDATE_SIGNING.md) است. فایل JKS را در Git قرار نده.
Workflow بدون این کلید ثابت متوقف می‌شود تا APK با امضای موقت و غیرقابل‌به‌روزرسانی منتشر نشود.

## فایل‌های تصویری و فونت

آیکن نصب برنامه همان تصویر اصلی در `icons/drawable-nodpi/novel_reader_icon.png` است. آیکن‌های رابط کاربری به‌صورت VectorDrawable XML در `icons/drawable/` نگه‌داری می‌شوند و با تغییر رنگ پوسته نمایش داده می‌شوند. پوشهٔ `icons/` به‌عنوان منبع Android تنظیم شده تا هیچ فایل آیکنی بیرون آن نباشد. فونت وزیرمتن و مجوز آن داخل `app/src/main/assets/fonts/` قرار دارند.
