کتابخانه‌ی کتاب‌ها
=================

وب‌اپ ساده و سازگار با موبایل برای مدیریت کتاب‌ها و خواندن یا ویرایش فصل‌ها.

امکانات
-------
- افزودن کتاب از منوی کناری، با تگ‌های از پیش تعریف‌شده
- افزودن تگ و فیلتر چندتگی کتاب‌ها
- پسند و نپسند کتاب‌ها
- وضعیت خوانده‌شده/خوانده‌نشده‌ی فصل با کنترل دستی
- خواندن و نوشتن فصل‌ها و واردکردن فایل‌های TXT یا Markdown
- ذخیره‌ی محلی کتابخانه در مرورگر و ذخیره‌ی فایل‌های فصل به‌صورت متن ساده
- نصب‌پذیری به‌صورت وب‌اپ (PWA)

اجرا
---
برای اجرای محلی Python را نصب داشته باش و در پوشه‌ی پروژه اجرا کن:

    py -m http.server 8000

سپس `http://localhost:8000` را در مرورگر باز کن. برای ذخیره‌ی پایدار، از همان مرورگر و همان آدرس استفاده کن. داده‌ها در دستگاه و مرورگر فعلی می‌مانند.

انتشار در GitHub Pages
----------------------
1. همه‌ی فایل‌های همین پوشه را به ریشه‌ی یک مخزن GitHub اضافه و push کن.
2. در مخزن، از Settings > Pages، انتشار از شاخه‌ی اصلی و پوشه‌ی `/ (root)` را انتخاب کن.
3. فایل‌های SVG، آیکن‌ها، `manifest.webmanifest` و `sw.js` را همراه `index.html` و `app.js` نگه دار.
