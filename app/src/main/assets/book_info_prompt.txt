اطلاعات کتاب زیر را از منابع معتبر پیدا کن. عنوان و نویسنده‌ای را که داده‌ام حفظ کن و اطلاعات نامطمئن را حدس نزن.

عنوان کتاب:
نویسنده:
مجموعه:

فقط یک شیء JSON معتبر برگردان؛ بدون توضیح، مقدمه، Markdown یا ```.
دقیقاً از این فیلدها استفاده کن:
- title: نام کتاب به صورت رشته
- author: نام نویسنده به صورت رشته
- description: توضیح کوتاه و بدون اسپویل به زبان فارسی
- genres: آرایه‌ای از ژانرهای اصلی کتاب
- chapterCount: تعداد Chapterها به صورت عدد صحیح؛ اگر مطمئن نیستی 0
- collection: نام مجموعه به صورت رشته؛ اگر کتاب مجموعه ندارد رشتهٔ خالی
- seriesNumber: شمارهٔ کتاب در مجموعه به صورت عدد صحیح؛ اگر مشخص نیست 0
- coverUrl: لینک مستقیم HTTPS به فایل تصویری جلد رسمی کتاب با بالاترین کیفیت و وضوحی که پیدا می‌کنی؛ لینک صفحهٔ وب نباشد. اگر لینک مستقیم و قابل دانلودِ مطمئن پیدا نکردی، رشتهٔ خالی بگذار.

  "chapterCount": 0,
  "collection": "",
  "seriesNumber": 0,
  "coverUrl": ""
}
